VOID PORTFOLIO
==============

Open it
-------
Double-click index.html. It runs in any modern browser and needs no build step.
(Fonts load from Google Fonts, so you need an internet connection for the comic lettering.)

Put it online for free (GitHub Pages)
-------------------------------------
1. Create a new repository on GitHub (for example: voidxv111.github.io).
2. Upload index.html to the repository.
3. Go to Settings > Pages, choose the main branch, and save.
4. Your site appears at https://<your-username>.github.io/

Edit it
-------
- Colors live at the top of the <style> block (--red, --gold, --cyan, --paper).
- Light and dark themes are the :root and :root[data-theme="dark"] blocks.
- Light mode (KAIZER) and dark mode (VOID, cybersecurity only) are separate content blocks: look for class="lt" (light) and class="dk" (dark) in index.html.
- Update your LinkedIn link by searching for "linkedin.com" in index.html.
